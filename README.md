# 메테오 포커

가입 없이 방을 만들고 링크, QR, 방 목록으로 팀원을 초대하는 실시간 플래닝 포커입니다.

## 실행

```sh
npm install
npm start      # 기본 포트 3000
npm test
```

같은 네트워크의 기기는 시작 로그의 `Network` 주소로 접속합니다. `localhost`로 열어도 공유 링크와 QR에는 LAN 주소가 들어갑니다.

| 환경 변수 | 설명 |
| --- | --- |
| `PORT` | 서버 포트 (기본 3000) |
| `PUBLIC_URL` | 공유 링크와 QR에 넣을 주소. 리버스 프록시나 터널 뒤에서 실행할 때 지정 |

## 동작 규칙

- 시작 화면에 서버에 있는 방 목록이 나옵니다. 방을 만들 때 이름과 비밀번호는 선택 사항입니다.
- 비밀번호는 해시로만 저장하고, 링크나 QR로 들어와도 입력해야 합니다. 이미 방에 있는 참가자가 재접속할 때는 다시 묻지 않습니다.
- 방 상태는 서버 메모리에만 있어서 서버를 재시작하면 모든 방이 사라집니다.
- 투표값은 공개 전까지 서버 밖으로 나가지 않습니다.
- 나가기를 누르면 즉시 방에서 빠집니다.
- 창을 닫는 등 연결이 끊긴 참가자는 60초 동안 자리와 투표가 유지되고, 그 뒤 제거됩니다. 방장이 제거되면 남은 참가자에게 방장이 넘어갑니다.
- 참가자가 모두 나간 방은 30분 뒤 삭제됩니다.
